# 背题助手 —— 使用说明

一个**响应式背题/刷题网页应用**，手机、平板、电脑的浏览器打开同一个网页即可使用，无需安装。

**核心思路：换题库 = 换网站。** 整个应用的逻辑（界面、刷题、背题、错题本、记忆曲线）是固定框架，题目内容全部放在 `questions.js` 一个文件里。你只要换掉这个文件（或把题目给我，我帮你生成），就是一个全新的背题网站。

---

## 一、怎么打开（三选一）

### 方式 A：直接双击（最简单，单机用）
双击 `index.html`，会用默认浏览器打开。手机上可用浏览器打开这个文件（或通过网盘/微信传到手机后打开）。

> 注意：直接双击走的是 `file://` 协议，功能基本都正常，但个别浏览器会限制本地存储。**推荐方式 B**。

### 方式 B：本地起一个服务器（推荐，局域网内多设备都能访问）
在项目目录下运行任意一个命令：

```bash
# Python（电脑装了 Python 即可）
python -m http.server 8080

# 或 Node.js
npx http-server -p 8080
```

然后在**同一局域网**的任何设备浏览器里打开 `http://电脑的IP:8080`（电脑 IP 可用 `ipconfig` 查）。

### 方式 C：部署到公网（任何人都能打开）
把整个文件夹上传到任意静态托管服务，拿到一个网址即可全球访问：

- **GitHub Pages**：仓库里放这些文件 → Settings → Pages → 得到 `https://xxx.github.io/...` 网址
- **Netlify / Vercel**：拖拽文件夹上传，几秒钟得到一个公网网址
- **Cloudflare Pages / 腾讯云 COS / 阿里云 OSS**：同理

> 部署到公网后，任何手机/电脑输入网址就能打开，无需登录。

## 二、怎么换题库（生成不同网站）

### 方法 1：你自己改 `questions.js`（推荐）
用记事本打开 `questions.js`，把 `QUESTION_BANK = [ ... ]` 里的题目换成你的题目即可。文件顶部有**详细字段说明和示例**。

### 方法 2：把题目发给我
把题目内容（Word / Excel / 文本 / 截图都行）发给我，我帮你生成一份新的 `questions.js`，你覆盖原文件后刷新网页即可。

### 方法 3：网页内手动录入 / 导入
- 打开网页 → 底部「🗂️ 题库」→「＋ 添加题目」可一题题录入
- 右上角「⚙️」→ 可**导入 JSON / CSV 文件**（Excel 可另存为 CSV）批量导入，也可导出备份

## 三、题目字段说明

```js
{
  id: "q1",              // 唯一编号，不要重复
  type: "single",        // single单选 | multiple多选 | judge判断 | fill填空 | short简答
  category: "计算机基础", // 分类/章节，用于分组筛选
  tags: ["重点", "易错"], // 标签数组，可选
  question: "题干文字",
  options: ["A", "B", "C", "D"], // 仅单选/多选需要；判断可不填
  answer: "B",            // 答案，规则见下
  explanation: "解析",    // 可选
  difficulty: 2,          // 难度 1~5，可选
}
```

**答案填法：**

| 题型 | type | answer 示例 |
|------|------|-------------|
| 单选题 | single | `"A"` |
| 多选题 | multiple | `["A","C"]` 或 `"AC"` |
| 判断题 | judge | `"正确"` 或 `"错误"` |
| 填空题 | fill | `"北京"`，多个可接受答案 `"北京\|北京市"` |
| 简答题 | short | `"参考答案文字"`（刷题时人工判对错） |

**CSV 导入列顺序**：`题型,分类,题干,选项,答案,解析,标签`（选项用 `||` 分隔）。

## 四、已实现的功能

### 核心功能
- ✅ **背题模式（翻卡）**：先看题，点卡片翻面看答案，标记「记住/没记住」
- ✅ **刷题模式**：单选/多选/判断/填空自动判分，简答人工判分，结束出成绩单
- ✅ **错题本**：答错自动收集，可单独重刷/重背，答对自动移出
- ✅ **收藏**：重点题标记，快速筛选
- ✅ **随机 / 顺序 / 按章节 / 按题型** 灵活出题
- ✅ **分类管理**：按分类/章节分组
- ✅ **答题统计**：正确率、已刷题数、分类进度条

### 进阶功能
- ✅ **记忆曲线复习（艾宾浩斯）**：记住→间隔 1/2/4/7/15/30 天自动安排复习，忘记→提前复习
- ✅ **题库导入/导出**：JSON / CSV 导入，JSON / CSV 导出备份
- ✅ **多题型**：单选、多选、判断、填空、简答
- ✅ **搜索 & 筛选**：按关键词、分类、题型筛选
- ✅ **语音朗读**：右上角 🔊 开启后自动读题，点卡片答案可朗读
- ✅ **夜间/护眼模式**：右上角 🌙 切换，自动记忆

---

## 五、数据存在哪

进度（错题、收藏、记忆曲线、统计）保存在**当前浏览器的 localStorage** 里。因此：

- 换浏览器 / 换设备，进度不互通 —— 需要的话在「⚙️」里**导出 JSON 备份**，新设备再导入
- 要「云端同步进度」需要加账号系统 + 后端，属于后续可扩展项
